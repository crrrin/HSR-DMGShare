# Asset provenance

Portrait PNGs were downloaded from the image links supplied by the user:
https://huggingface.co/datasets/fffffffff1/assets/tree/main/spriteoutput/avatariconteam

Base character ID/name labels were extracted from the supplied character catalog HTML. Variant and skin associations were supplied by the user. The exact selected associations and filenames are in catalog.json.

No ownership or redistribution license for these game assets has been verified. The code has no license declaration at this stage. Keep that distinction in mind when choosing what to publish to a public repository.
